# 🚬 More Smokes (Build 41 Legacy)

**The end of the world didn’t kill off smoking it made it easier to get everything you want**  
This mod expands Project Zomboid’s cigarette system and introduces cannabis as a lootable, smokable item, with custom textures, balanced effects, and brand diversity.

This is the **final release for Build 41**, preserved for multiplayer compatibility and servers not yet upgraded to Build 42.

> ⚠️ Please do not reupload or include this mod in modpacks without permission from the creator.

---

## 🔥 Features

### ✅ Expanded Smoking System
- Adds multiple fictional cigarette brands with unique textures
- Introduces cannabis as a consumable (rolled joints, bud packs, etc.)
- All items use new custom sprites for immersive inventory visuals

### 🌿 Mary Jane Mechanics
- Moodles impact stress and hunger based on item potency
- Controlled balancing avoids overpowered effects
- Designed to feel like an authentic part of PZ’s apocalypse

### 🔧 Optional Add-On Support
- “Easy Packing” toggle included for lighter gameplay setups
- Flexible with sandbox environments and loot tables

---

## ✅ Compatibility

- ✔️ Compatible with **Project Zomboid Build 41**
- ❌ Not yet updated for Build 42 (which changes item handling and inventory visuals)

> A Build 42-compatible version will be maintained on the `main` branch of this repo.

---

## 💾 Manual Installation

1. Download the Build 41 release:  
   👉 [Release vB41.0](https://github.com/RHay6868/pz-mods-more-smokes/releases/tag/vB41.0)  
   Or [Download ZIP directly](https://github.com/RHay6868/pz-mods-more-smokes/archive/refs/tags/vB41.0.zip)

2. Extract the folder to your mods directory:

C:\Users\YourUsername\Zomboid\mods\

3. Launch the game and enable the mod in the **Mods** menu
